# 宽屏三栏文档布局设计

## 目标

将指南页和组件页改成参考站点所示的三栏文档工作台，减少宽屏下无效留白，让 Demo、代码块和 API 表格使用主要可用空间。首页保持现有独立全宽布局。

## 桌面布局

- 顶栏横跨视口，不受正文最大宽度限制。
- 左侧导航固定为约 `260px`，保持当前分组和折叠交互。
- 右侧本页目录固定为约 `220px`。
- 中间正文使用剩余空间，不再受 VitePress 默认 `688px`/`1080px` 内容上限限制。
- 正文左右保留 `32px` 至 `48px` 安全边距，避免内容贴边。
- 页面整体只保留一个宽度约束来源，删除会互相覆盖的重复 `max-width` 规则。

## 内容宽度

- 普通正文、DemoBlock、代码块和 API 表格均在同一内容栏内。
- DemoBlock 和背景类组件默认占满内容栏。
- 文字段落不额外设置窄栏，以便与参考站点保持一致；页面目录负责提升长页的可导航性。

## 响应式行为

- 大于等于 `1440px`：完整三栏，正文弹性扩展。
- `960px` 至 `1439px`：保留左栏，隐藏右侧目录，正文占满剩余空间。
- 小于 `960px`：沿用 VitePress 的移动端导航抽屉，正文单栏并使用较小边距。

## 实现边界

- 主要修改 `docs/.vitepress/theme/custom.css`，必要时调整 VitePress 布局变量。
- 不改组件公共 API、文档内容结构或首页视觉设计。
- 不复制参考站点品牌、文字或组件，仅复用其空间分配方式。

## 验收

- 2560px 宽屏下正文明显扩大，两侧不再出现大块无效空白。
- 组件页 Demo 与代码区能利用正文宽度。
- 左侧导航和右侧目录不遮挡正文。
- 1440px、1024px 与移动端没有横向滚动。
- 文档构建、现有测试和 Chrome 视觉检查通过。

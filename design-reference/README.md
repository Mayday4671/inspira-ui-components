# Inspira UI Components · 高保真重设计交付包

这是从用户当前页面截图重新设计的**可交互前端原型 + 浏览器截图 + 阶段施工提示词 + 验收标准**。目标是让现有 Inspira UI 封装库的文档站更像成熟的 Element Plus 风格开发者站：简洁清楚、动画预览突出、没有到处都是的滚动条。

## 如何查看

双击 `index.html` 直接打开，或者在目录运行 `python -m http.server 5175` 后访问 `http://localhost:5175`。界面支持顶部导航、首页/目录/详情/指南/主题、组件类别筛选、全文搜索（Ctrl+K）、暗色切换、详情参数修改、复制代码、示例弹窗、窄屏侧边导航。

## 如何交给智谱实现

将本目录解压并复制到现有项目内部的 `design-reference/`（避免替换真实源码），然后把 `交付给智谱的开发提示词.md` 的全文发送给智谱。要求它首先盘点真实项目，随后按 A~F 阶段修改、截图比对、验证。

## 重要说明

- 这是**交互视觉原型**，不是已编译的 Vue 3 npm 组件库。部分演示动画是原型 CSS，用于说明预期交互，开发时必须绑定项目真实组件。
- 根据截图可识别出 20 个组件名；截图中的现有站点声称 22 个，但没有仓库源码，另外 2 个不应猜测。正式发布时数据与文档都应从源码中校验。
- 示例包名 `inspira-ui-components` 参照截图，真实打包名、导出方式与 API 以现有仓库为准。
- 附带的截图来自浏览器对本原型的实际渲染，可供视觉对照。建议优先看 `截图-首页-1440.png`、`截图-组件总览-1440.png`、`截图-组件详情-1440.png`、`截图-快速开始-1440.png`。
- 此包不更改你的原项目、不改你已有的动画与封装逻辑。

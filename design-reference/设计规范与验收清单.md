# Inspira UI Components · 视觉设计规范与验收清单

## 设计定位

一个类似 Element Plus 使用体验的 Vue 3 动效组件库文档站。视觉取向是现代、简洁、偏开发者工具的精致感，重点展示可运行效果，不做大面积夸张光效、不靠长篇营销文案堆首屏。

## 页面与原型路径

本包内 `index.html` 为可离线打开、可点击的原型：

| 页面 | 原型路由 | 重点 |
|---|---|---|
| 首页 | `#/home` | 价值主张 + 实时动效 + 精选组件 |
| 组件总览 | `#/components` | 搜索、类别筛选、组件预览网格 |
| 组件详情 | `#/component/shimmer-button` | 动态演示、控制台、代码、API、TOC |
| 快速开始 | `#/guide` | 安装命令切换、按需/全局使用 |
| 主题定制 | `#/themes` | 主题预览、变量、暗色切换 |

> **范围说明**：这是供施工对照的高保真设计与部分交互原型，不是完整 Vue 组件库源码。组件总览根据用户截图可辨认的名称展示 20 个示例；截图现有站点显示“22 个组件”，另两个无法从截图可靠确认，最终清单必须以用户项目真实导出为准。原型中的演示 API 与包名也要以实际代码核验后替换。

## 布局规则

- 顶栏：68px，移动端 62px，始终只占一条水平区域。
- 桌面文档页：左侧 249px，正文为自适应 `minmax(0,1fr)`，右侧 TOC 175px；中间采用单个自然文档滚动。
- 组件演示卡片：优先完整展示 Preview，参数控件在卡片内部的底部布局，但不得为 Preview 新开固定高度滚动盒。
- ≤1020px：隐藏右侧 TOC；≤760px：左侧变成按需打开的抽屉；≤480px：组件目录切换为可读的单列卡片列表。
- 正文 `max-width` 限制阅读行宽，不要在 1920px 桌面上把内容挤成 500px 的一根窄柱。

## 滚动条零混乱规则

**硬目标：用户正常浏览时，浏览器只看到一条主页面的纵向滚动条。**

1. 页面以 `html/body` 的正常文档流滚动，不把 `main` 设为独立滚动宿主。
2. 左侧导航在内容过长时可滚动，但 scrollbar 隐藏，避免双滚动条视觉混乱；侧栏分组可折叠。
3. 右侧目录与普通内容不拥有独立 `overflow-y:auto`。
4. 演示区域不设纵向滚动；长代码块仅在必要时允许自身水平方向滚动。
5. `document.documentElement.scrollWidth <= window.innerWidth` 在 1920/1440/1024/768/390 均必须成立。
6. 弹窗或命令面板开启时可以锁定背景滚动，但关闭后必须恢复，不得导致页面跳动。
